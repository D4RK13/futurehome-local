# Futurehome Local

A Homey Pro app for Futurehome devices. The devices run directly on Homey's
Zigbee and Z-Wave, with no Futurehome hub, cloud, app or subscription.

**Status:** planning. There is no app to install yet.

Not affiliated with Futurehome AS or FHSD Connect AS. For the official Homey
app, see "Futurehome" in the Homey App Store.
